# Roadmap

方向级，不是承诺清单；术语见 `CONTEXT.md`。整体规划在 forge 的 Epic「anvil v1 规划」（anvil-k0t）里进行，目标是一份覆盖下面三项需求的 v1 spec。

- **额度利用率**：缓存保活 + 冷发送守卫。长会话中途离开时缓存不过期，回来误发冷消息前先拦一次。
- **显示**：看见什么、放在哪、什么形态整体设计；会话仪表盘（以 flightdeck 为蓝本）和 statusline（与 anvil 分工后重做，或由 anvil 覆盖后取消）都在这里。
- **英文沟通**：翻译输入框，中文写、英文发；翻译后端可接自有大模型 API，也可用订阅内模型。

三项需求共用缓存状态（额度利用率据此行动，显示把它展示出来）和同一块屏幕（显示的内容与翻译输入框一起分配位置）。
