# 只做全屏一种布局，statusline 并入 anvil 面板

> Source: anvil-k0t (D7)

anvil 的显示只为全屏渲染设计：右侧停靠、可拖宽的 anvil 面板，加主输入框上方的翻译输入框；不适配经典渲染和内联，也不做随宽度切换的多种布局，终端窄于 110 列时引擎自行把面板放成内联，不另做设计。用户的终端都是全屏渲染，只做一种布局才能把它做到最好；statusline 的内容（目录与 git、模型、用量、缓存）全部移进面板，用户的 statusline 脚本退役。代价是经典渲染下的显示不保证可用。

**2026-10-14 部分推翻**：statusline 恢复（用户定）。mod 拿不到第一次请求前的 effort、真实的缓存过期时刻，面板上这些值常常不对；引擎直接交给 statusline 的值（目录与 git、模型与 effort、上下文、缓存过期、5h/7d、花费）从面板拿掉，面板只留 anvil 自己才有的。只做全屏一种布局不变。
