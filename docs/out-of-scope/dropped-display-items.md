# 面板不放的显示项

**决定**：下列内容在 v1 设计里删掉或不做，面板和每段回复末尾都不显示：会话时长；单轮回执里的用时和用量（每段回复末尾只接 token/s 和首字）；会话框；上一轮、上一条消息的数值；保活续期记录；缓存读写数量；事件流水；请求次数；干活 / 空闲；权限模式；advisor；loops；图标的纯文本回退。

**理由**：这些是用户逐项定稿面板内容时（anvil-k0t.10、.35）删掉的：每段的用时原生收尾那行已经有；缓存框、用量框只写判断要用的结论（命中率、过期时刻、保活状态、各项百分比和预测），不写过程数值；用户各台电脑都装了 Nerd Font，不需要纯文本回退。
